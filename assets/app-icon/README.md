# Design System app icon

The Design System mark (a 2x2 grid of blocks, `docs/brand/design-system-mark.svg`) on a dark rounded tile (`artcraft-launcher.svg`). Original artwork for this fork, under the repository's MIT OR Apache-2.0 license. Every PNG, the `.ico` and the `.icns` here are rendered by `packaging/brand/generate.ps1`; the file names keep the upstream `artcraft-launcher` stem only because the build scripts refer to them.
